# Data Structures konsol tətbiqi

Tapşırıqdakı 5 mövzunu əhatə edən konsol proqramı (Python 3, əlavə kitabxana lazım deyil).

```bash
python cli.py
```

| Menyu | Nə var |
|---|---|
| 1. Array və Dynamic Array | sabit və dinamik array; əlavə, silmə, axtarış vaxtı 1k / 10k / 50k elementdə |
| 2. Singly və Doubly Linked List | hər iki siyahı; əməliyyatların müqayisəsi və yaddaş |
| 3. Stack, Queue, Deque | sadə brauzer: geri/irəli (stack), yükləmələr (queue), son baxılanlar (deque) |
| 4. Hash Table | öz hash table, collision chaining ilə; rehash, load factor ölçümü |
| 5. Binary Search Tree | əlavə, axtarış, silmə; sıralı verilənlərin ağaca təsiri |

Hər bölmədə əmrlərlə strukturla işləmək olur, `bench` tam hesabatı və vaxt ölçümünü göstərir, `q` menyuya qaytarır.

```
ds/arrays.py        FixedArray, DynamicArray
ds/linked_lists.py  SinglyLinkedList, DoublyLinkedList
ds/stack_queue.py   ArrayStack, LinkedQueue, Browser
ds/hash_table.py    ChainingHashTable
ds/bst.py           BST
cli.py              konsol menyusu
```
